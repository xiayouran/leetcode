## 蛮力法
    对问题所有可能的解或状态逐一进行测试，直至找到可行解，或将所有可能的状态都测试完毕。也叫暴力法、穷举法。
  - 冒泡排序(BubbleSort)
    - 思路：
      - 采用蛮力策略，将待排序序列看作两部分：已排序和未排序
      - 对未排序的相邻两数进行两两比较，如果发现反序就交换
      - 一轮比较后，最大的数被换到最后一个位置(升序)
      - 如果某一轮比较中没有交换，则说明数据已经排好序，可以提前结束排序
    - 解：
      - 两层循环，外层用于轮数循环，内层用于比较
      - 提前结束标志
  - 直接选择排序(SelectSort)
    - 思路：
      - 采用蛮力策略，将待排序序列看作两部分：已排序和未排序
      - 每次从待排序元素中选择最小的元素(升序)与当前位置交换
      - 逐步缩小待排序范围，直到全部有序
    - 解：
      - 两层循环，外层用于轮数循环(也可以理解为控制当前位置)，内层寻找最小值
      - 记录最小值位置，最后进行交换
  - 直接插入排序(InsertSort)
    - 思路：
      - 采用蛮力策略，将待排序序列看作两部分：已排序和未排序
      - 每次从未排序部分取出第一个元素，插入到已排序部分的正确位置
      - 通过将已排序部分中比该元素大的元素向后移动，直到找到合适位置插入
    - 解：
      - 外层循环遍历未排序部分
      - 内层循环在已排序部分中寻找插入位置并进行移动
